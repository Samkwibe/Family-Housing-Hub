## 🔧 TECHNICAL DETAILS:

### Web Speech API:
```javascript
const utterance = new SpeechSynthesisUtterance(text);
utterance.rate = 1.0;        // Speed
utterance.pitch = 1.0;       // Tone
utterance.volume = 1.0;      // Loudness
utterance.lang = 'en-US';    // Language
window.speechSynthesis.speak(utterance);
```

### Priority System:
```javascript
// High priority (cancels ongoing speech)
speak("Navigation started", "high");

// Normal priority (queues)
speak("Turn right", "normal");
```

### Smart Timing:
- Start announcement: Immediate
- First turn: 3 second delay
- Each turn: As you approach
- Repeat: On demand
